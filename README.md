## 🚀 Installation

```bash
git clone https://github.com/VishalPaswan2402/express-crud-factory-test.git
cd express-crud-factory-test
npm install
```

## ▶️ Run Tests

Run all tests :
```
npx playwright test
```

Run tests with browser visible :
```
npx playwright test --headed
```

Run a specific test :
```
npx playwright test tests/example.spec.js
```

View the HTML report :
```
npx playwright show-report
```
